# CVEscore v2: label-harmonisation ablation

Same time split as v1 (train < 2025, validation Oct–Dec 2024, test 2025+). CVSS scores and vectors quoted in descriptions are stripped for every v2 system. Generated by `scripts/ablation_report.py`.
